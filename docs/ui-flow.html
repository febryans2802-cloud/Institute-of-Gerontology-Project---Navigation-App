Gaps found while mapping the flow

No way to resume a session after the researcher app restarts

The session id is built from the participant code and the current minute, and completed blocks live only in memory. A crash between Block 1 and Block 2 forces a new session, splits the participant's data across two ids, and loses the record of which block was done. Fix: save the session state to disk and offer “Resume P07 session” on the Setup screen.

The vibration recognition check has no screen

The protocol (§2.2) requires participants to identify ≥ 90% of patterns while walking, but the practice walk only plays prompts. Results would have to go into free-text notes. Fix: a short “pattern check” mode on the researcher phone: play a random pattern, tap what the participant said, log the score.

Missing GPS is invisible to the researcher

If location permission is denied, only a small orange dot on the participant phone shows it, and that phone is in a pouch. Fix: send the permission state in the hello message and show it in the researcher's status bar before Start block.

Not drawn because they are outside the app: consent, screening, the Borg and NASA-TLX questionnaires, and the IMU and camera setup. They happen on paper or other devices between the screens above.
